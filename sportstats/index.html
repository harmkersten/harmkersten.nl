Logo's worden eerst gezocht in je eigen logos/-map (alle submappen), dan in de football-logos GitHub-collectie, met TheSportsDB als laatste terugval. Werkt goed voor voetbalclubs, niet voor wielerploegen — daar kun je een kleur of eigen afbeelding per rij gebruiken.
Live ophalen van standen vanuit een externe API kan vanuit de browser vaak niet door CORS- en API-key-beperkingen. De aanbevolen route: een kleine Vercel serverless function als proxy (bv. /api/standings?competition=cl) die de externe API met je sleutel aanroept en schone JSON teruggeeft aan deze pagina.
Verwacht JSON: [{"team":"Liverpool","gs":5,"p":15}, ...]
