Data
De koppen boven de cijfers (GS, P, ...) zijn direct te wijzigen — typ er gewoon een nieuwe naam in. Met "+ Kolom toevoegen" zet je een extra statistiek erbij (bijvoorbeeld W, G, V); het ✕'je naast een kop verwijdert die kolom weer.
Met kop herkent de tool zelf welke kolommen je aanlevert (GS, W, G, V, P, eigen namen — alles mag), ook als rang en teamnaam los op hun eigen regel staan zoals bij een gekopieerde website-tabel. Een rangnummer dat per ongeluk vóór de teamnaam wordt geplakt, wordt automatisch verwijderd.
Live ophalen van standen vanuit een externe API kan vanuit de browser vaak niet door CORS- en API-key-beperkingen. De aanbevolen route: een kleine Vercel serverless function als proxy (bv. /api/standings?competition=cl) die de externe API met je sleutel aanroept en schone JSON teruggeeft aan deze pagina.
Verwacht JSON: [{"team":"Liverpool","gs":5,"p":15}, ...] — extra velden worden automatisch eigen kolommen.
Logo's
Zoekt in je eigen logos/-map op basis van manifest.json. Voor wielerploegen of ontbrekende clubs: gebruik het 📁-knopje naast de rij om een eigen PNG te uploaden.
